# 📦 StockFlow- Beta

Sistema de gerenciamento de estoque desenvolvido em **Python** utilizando **CustomTkinter**.

> ⚠️ Projeto em desenvolvimento (Beta).

## ✨ Funcionalidades

- 🔐 Tela de login
- 📦 Cadastro de produtos
- 📋 Listagem de produtos
- 🆔 Geração automática de ID
- 💰 Cadastro de preço e quantidade
- 🖼️ Interface gráfica com CustomTkinter
- 🔄 Navegação entre telas

## 🚧 Em desenvolvimento

- Banco de dados
- Persistência dos dados
- Sistema de vendas
- Pesquisa de produtos
- Edição e exclusão de produtos
- Relatórios
- Melhorias na interface
- Geração de executável (.exe)

## 🛠️ Tecnologias

- Python 3
- CustomTkinter
- Pillow (PIL)

## ▶️ Como executar

```bash
pip install customtkinter pillow
python main.py
```
